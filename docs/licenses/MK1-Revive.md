# MK1 Revive (bundled bridge)

RE-ANIMATOR includes, unchanged, the `mk1-bridge` from **MK1 Revive v0.3.6** by andy83
(https://github.com/andy83-projects/maschine-mk1-revive, release asset `maschine-mk1-revive-v0.3.6-macos.zip`),
at `reanimator/vendor/MK1 Revive.app`. SHA-256 of `mk1-bridge`: `d7dfd69a1a8700c3e10bcb22001599a4b2c75481c0a1d71accb9a8fe2181399b`.

**Permission:** Dennis confirmed on 2026-10-26 that the author gave permission to include MK1 Revive in RE-ANIMATOR,
on the condition that he is credited. (The upstream repository itself has no licence file, checked 2026-10-26.) If the
author's message is at hand, keep a copy in this folder too.

**Credit (required):** shown on RE-ANIMATOR's main window and in its README / tester guide:
"MK1 bridge: MK1 Revive by andy83 — github.com/andy83-projects/maschine-mk1-revive".

**Changed version (2026-10-27):** Dennis confirmed that the permission also covers **changing** the bridge.
RE-ANIMATOR now builds its own version from andy83's v0.3.6 source in `bridge/` (see `bridge/ORIGIN.md` for every
change); the credit reads "MK1 bridge: based on MK1 Revive by andy83". andy83's released binary stays in
`reanimator/vendor/` as the fallback.
